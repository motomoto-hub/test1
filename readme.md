# This is my first time using Git/ Github
## Let's Learn How it works 
- Basic Commands 
```
git status
git logs
git add 
git commit
git pull
git push

```


| Name | Describe | Example |
| --- | --- | --- |
| status | to check status of git | git status |
| logs | Used to check logs | git logs |
| add | add file or files | git add <filename> or git add . |
| commit | used to message commit | git commit -m "my first commit"
| pull | used to pull from central to local repo / remote | git pull origin main or git pull origin <branch_name>
| push | used to push from local repo / remote  to Central repo | git push origin main or fir push origin <branch_name>
